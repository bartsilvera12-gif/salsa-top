# Salsa Top — Sitio web

Landing page de **Salsa Top**, marca artesanal gourmet de salsas picantes, agridulces y untables (Paraguay).

## Contenido

- `index.html` — sitio completo en un solo archivo autónomo (no requiere dependencias ni build). Se puede abrir directamente en el navegador.

## Publicar en GitHub Pages

1. Creá un repositorio nuevo en GitHub y subí estos archivos.
2. Entrá a **Settings → Pages**.
3. En **Source**, elegí la rama `main` y la carpeta `/root`.
4. Guardá. En unos minutos el sitio estará disponible en `https://<usuario>.github.io/<repositorio>/`.

## Personalizar

- **Imágenes:** los espacios de foto (producto, finca, familia) son áreas donde se pueden arrastrar imágenes al abrir el sitio en el editor. Para la versión pública conviene reemplazarlas por imágenes fijas.
- **Contacto:** WhatsApp 0994 208 200 (Edson), Instagram, Facebook y TikTok ya están enlazados.

## Especificaciones de marca (manual)

**Tipografía**
- Textos de sachets y etiquetas: **Bahnschrift Bold Condensed** (negrita). Cuando el espacio es ajustado: **Swis 721 CN BT**.
- Logo Salsatop: **Swis 721 CN BT Bold** (negrita).
- Como Bahnschrift y Swis 721 CN BT no son fuentes web libres, el sitio usa **Barlow Condensed (Bold/Extra-Bold)** como equivalente web más cercano (misma estructura condensada y negrita) y **Barlow** para textos largos.

**Colores (Pantone → web)**
- Letras del logo: Negro 100% → `#000000`
- Fuego · Rojo (Pantone Red 032 C) → `#EF3340`
- Anaranjado (Pantone 151 C) → `#FF8200`
- Amarillo (Pantone 109 C) → `#FFD100`
- Base de marca (verde petróleo) → `#1E5155`
